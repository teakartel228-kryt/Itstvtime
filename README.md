# TV Time: Tenna & Multi-Biome (Fabric, Minecraft 26.3)

Сборка: `./gradlew build` (JDK 25) → `build/libs/tenna-tv-time-1.0.0.jar` в папку `mods/` вместе с Fabric API 0.167.0+26.3.
Версии (Loom 1.17, Loader 0.19.5, Gradle 9.6.0) взяты с fabricmc.net для 26.3.

## Что внутри
| Фича | Как работает |
|---|---|
| **Мультигенерация биомов** | 7 типов мира в списке «Тип мира»: Пустыни, Леса, Снега, Джунгли и болота, Горы, Океаны, Всё сразу. Первый биом набора — основной (занимает вдвое больше площади). Свой набор: `python3 tools/make_multibiome_preset.py my_world desert badlands savanna --out ./mypack` → готовый датапак (первый биом = основной). Графического выбора биомов в меню создания мира нет. |
| **Пластинки** | 4 диска (IT'S TV TIME, THAT MAKES YOU SCREAM, It's Time to End You, KAIZO) — твои mp3 в моно-ogg, формы ванильных дисков перекрашены в палитру Тенны (красный/фиолетовый/золотой/бирюзовый). Падают с боссом, могут выпасть из крипера от скелета. |
| **Зомби ломают блоки** | Формула игрока (скорость инструмента / твёрдость / 30, или /100 без нужного инструмента) × 0.8 (для ванильных зомби). Земля (0.5) ~19 тиков, доски (2.0) ~75 тиков. Копают вперёд, вверх и вниз к цели. Не ломают тверже 5.0 (обсидиан). |
| **Яйца призыва** | Зомби-копатель с разной **скоростью ломания блоков**: обычная (= игрок, ×1.0), быстрая (×2.0), медленная (×0.4). Бегают все как ванильные. Значения — в `config/tvtime.json`. |
| **Оружие** | Мечи, топоры, булава, лопаты/кирки работают через атрибуты; лук, арбалет, трезубец — зомби стреляют/бросают с дистанции 5–18 и отходят. Умные зомби подбирают оружие. |
| **Звук** | Громкий звук (громкость ≥1.5: взрывы, нотные блоки, рог козы…) → зомби в радиусе идут на точку, ищут игрока рядом и преследуют его ~20 с даже без видимости. |
| **Ловушки** | Капкан (раскрытые/сомкнутые челюсти, ПКМ — взвести) и шиповая плита. Свои JSON-модели, слой `CUTOUT_MIPPED` — мипмапы сохраняются. |
| **Броня Тенны** | 3/7/5/2 = 17 очков (железо 15, алмаз 20), прочность ×25 (15 / 33), твёрдость 1. Текстуры брони и иконки вырезаны из твоего скина (основа + второй слой скина как оверлей). Крафт из «Обломков ТВ». |
| **Босс Мистер Ант-Тенна** | 300 HP, броня 6 (как Иссушитель). Яйцо призыва или «Загадочный пульт». Музыка по фазам. |

### Босс — атаки (по вики, адаптировано под ваниль)
- **Звёздный состав** — кольца звёзд с проёмом, пройди через проём.
- **Резкий переход** — линия-разрез через арену после предупреждения, отойди от линии.
- **Римшот** — две смеющиеся звезды сами наводятся и растут, убеги/выжди.
- **С 50% HP — мини-игры:** падающие ТВ, «Кулинарное шоу» (веер огненных шаров), «Рок-концерт» (4 пульса — перепрыгивай).
- **Ниже 20% — Финальный эпизод:** быстрее атаки, приходят три «Майка» (зомби обычный/быстрый/медленный).
- Урон зависит от сложности (×0.7 / ×1 / ×1.35).
Не реализовано из боя: действия «Я ЛЮБЛЮ ТВ»/«Сопротивляться»/«Выключить» (в ванили нет ACT-меню).

Настройки: `config/tvtime.json` (зомби-ИИ можно выключить, в т.ч. для ванильных зомби).

## ⚠ Не компилировалось
В среде, где писался мод, нет доступа к Maven Fabric, поэтому проект **не собирался и не запускался**; синтаксис проверен, API 26.3 сверен с docs.fabricmc.net частично. Если Gradle ругнётся, вероятные места:
- `ArmorType.getDurability(...)` (ModItems), `GameRules.MOB_GRIEFING` (SmartAI)
- пакеты снарядов `entity.projectile.arrow.*` / `hurtingprojectile.SmallFireball`
- `entityInside(...)` с 6 аргументами (блоки-ловушки), `BlockRenderLayerMap.putBlock`
- `FabricItemGroup.builder()` (ModTabs), конструкторы `HumanoidMobRenderer`
- Хук звука в `ServerLevelSoundMixin`: если метод в 26.2 называется иначе, мод запустится, но зомби не будут слышать звуки (в логе не появится строка «noise hook is active»).
